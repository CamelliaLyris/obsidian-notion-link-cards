# Notion 链接卡片

按 Notion 的链接粘贴体验制作的独立 Obsidian 插件，不依赖 Notion 账号或其他插件。

启用后，在笔记正文粘贴单个 HTTP(S) 链接，选择 URL、提及（带网页标题的 Markdown 链接）、书签（封面卡片）或嵌入。取消菜单仍保留原链接。代码块、行内代码、多行文本、文件粘贴和已选择文本的替换保持原行为。也可执行「插入链接卡片」「将所选链接转为书签卡片」命令。

书签从网页 Open Graph/Twitter/HTML 信息中提取标题、简介和封面，封面默认保存到本地「链接卡片附件」。信息保存在笔记的 link-card 代码块中，阅读视图和实时预览显示卡片；源码模式显示 JSON。右键卡片可修改标题、简介和封面，封面支持库内路径或 HTTP(S) 图片链接。旧附件不会自动删除。网站需登录、反爬或只在客户端生成数据时可能无法自动提取，仍可手工编辑。

嵌入支持网易云音乐歌曲、Bilibili BV 视频和 YouTube 视频；其他链接降级为书签。选择嵌入后直接加载网站播放器，不需要额外点击加载按钮；网易云采用紧凑音乐外链播放器，视频采用 16:9 播放器。仅加载界面，不自动播放。已有嵌入代码块同样直接显示播放器。嵌入区域边缘右键可打开原链接。实际播放器样式和是否能播放由网站决定，可能受到版权、登录、网络或网站嵌入政策限制；未复制 Notion 私有播放器实现。提及是标题链接，不连接 Notion 人员/页面。初次选择书签或提及时会请求目标网站；保存本地封面失败时会保留远程地址并提示，远程图片显示依赖网络。图片保存限制 10 MB（响应后检查），网页读取最长等待 20 秒。

异步获取期间笔记发生变化会取消替换以避免覆盖新内容。无自动后台全库抓取。关闭插件后普通标题链接仍可用，卡片仍保留原始网址和全部 JSON 数据。
